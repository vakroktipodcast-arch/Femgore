# Anchors

Prose the author has signed off as *the voice*. Every drafter reads every file here before writing a word.

Phase 1 puts four files here, in this order:

1. `ch17.md` — the set piece; the lush, hungry pole of the voice
2. `ch01.md` — the opening; the voice at rest
3. `ch25.md` — the numb pole; the inverse of 17
4. `interlude-2-cam.md` — the close-third register for interludes

Nothing goes in this folder until the author approves it. Once approved, copy the file to `manuscript/` as well.

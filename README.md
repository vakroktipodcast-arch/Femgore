# The Butcher's Syllabus

A femgore novel by Imogen Sallow. Working repository.

- **How to work:** `PLAYBOOK.md`
- **Rules for every agent:** `CLAUDE.md`
- **The book's bible:** `bible/` (strategy, cast, style)
- **Chapter briefs:** `outline/` — start with `00-reading-order.md`
- **The voice standard:** `anchors/`
- **Fixed facts:** `ledger/continuity.md`
- **Agents:** `.claude/agents/` — beat-sheet, continuity, drafter, interlude-drafter, reviser, and five single-lens reviewers
- **Checks:** `scripts/lint.py`, `scripts/status.sh`, and a GitHub Action that lints every pull request touching `manuscript/`

Private. Not for distribution.
